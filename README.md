# wis_zn_electrolyte_site

Research microsite for the ICEMEE 2026 manuscript on machine-learning analysis of organic co-solvents for water-in-salt zinc-ion battery electrolytes.

## stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- Framer Motion

## commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`
- `python scripts/build_site_data.py`

## notes

- Static and GitHub Pages friendly
- Uses `src/data/generated/siteData.json` for the site payload
- Keeps the paper PDF under `public/paper/`
